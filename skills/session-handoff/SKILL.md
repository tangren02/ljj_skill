# 会话交接

面向完全没读过当前会话的接手者，提炼足以接续工作的上下文。适用于代码任务和普通讨论。

## 整理范围

以用户指定的主题或下一会话目标为准；未指定时，围绕当前尚未完成的目标整理。已完成的事项只保留后续仍需要的部分。

按实际需要保留：

- 当前目标和必要背景。
- 已完成、进行中和待办事项，以及实际停在哪里。
- 已确认的结论、决定及理由。
- 用户的约束、偏好和已排除的方向。
- 未决问题、阻碍和已确认的下一步；尚未确定下一步时如实说明。
- 接续需要的文件、链接或验证结果。

采用用户最新明确确认的决定，区分事实、假设和未验证事项。已有文档或其他产物用必要摘要加路径或 URL 引用；交接文本本身应说清目标和当前状态。省略无关话题、重复内容和过程流水账，并对敏感信息脱敏。

## 交付

默认在当前聊天输出一个可直接复制的 Markdown 代码块，沿用用户的语言。根据实际内容组织小节，省略空项。

用户明确要求保存文件时再保存，并返回文件位置。

交付完整交接内容即完成本次请求。
